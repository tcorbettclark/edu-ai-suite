# Browser LM handoff

## Status

The browser demo works for the trained Wilde corpora. TinyStories is prepared and
committed, but its training run has not completed, so `out/tiny_stories/` is empty.

`out/` is intentionally gitignored. A fresh clone contains the training scripts and
corpora but **not** the exported JSON; every model must be regenerated by running the
pipeline below.

## What this is

Tiny character-level and word-level LSTMs are trained offline, exported as JSON, and
run in JavaScript. The browser shows the next-token distribution after every token and
lets the reader sample, undo, reset, or force a candidate. This is a teaching widget,
not a transformer and not ChatGPT.

The page is deliberately honest about the model: it sees only the last 12 word tokens
or 24 characters.

## Run it

Run this outside the 2 GiB Apple container. Inside that container, TensorFlow plus the
editor's language servers sit at the memory limit with no swap; the first epoch did not
finish in six minutes. With enough memory, the first epoch prints in roughly 30 seconds.

```bash
cd edu-ai-suite

# 1. Train (choose one corpus)
BROWSER_LM_CORPUS=tiny_stories uv run python examples/browser_lm/train_export.py

# 2. Rebuild the Python reference from the saved weights
BROWSER_LM_CORPUS=tiny_stories uv run python examples/browser_lm/make_reference.py

# 3. Pack the browser files
BROWSER_LM_CORPUS=tiny_stories uv run python examples/browser_lm/compact_export.py

# 4. Check JS greedy output against the Python reference
node examples/browser_lm/test_infer.js tiny_stories

# 5. Serve and open
cd examples/browser_lm
python3 -m http.server 8123
# http://127.0.0.1:8123/?corpus=tiny_stories
```

`BROWSER_LM_CORPUS` defaults to `dorian_gray`. `train_export.py` writes
`char.json`, `word.json` and `manifest.json`; `compact_export.py` writes
`char.compact.json`, `word.compact.json` and `browser_manifest.json`.

The training command should be run in the foreground so its epoch lines are visible.
`train_export.py` sets line buffering, so piping through `tee` is safe.

## Design notes

- Checkpoints are snapshots at epochs `0, 5, 20, 50`, not live browser training.
- Character weights are float32; word weights are int8 with one scale per matrix row.
  Per-row scaling is required for exact greedy parity; per-tensor int8 changed argmax
  results on Dorian Gray.
- The default browser view is character-level. Word-level is a selector. Both bars and
  treemap views are available.
- Default prompts: `dorian_gray` = `the port` / `the portrait`;
  `happy_prince` = `the sw` / `the swallow`;
  `tiny_stories` = `Once upon a` / `Once upon a time`.
- `manifest.py` writes the run manifest. There is no separate repair script.
- `out/` and `__pycache__/` are ignored.

## Files

| file | purpose |
|---|---|
| `corpus.py` | corpus selection, source metadata, cleaning and start/end slicing |
| `train_export.py` | trains both tokenizations and exports checkpoints |
| `make_reference.py` | rebuilds checkpoints and writes greedy references |
| `manifest.py` | writes `manifest.json` from the two exported models |
| `compact_export.py` | packs weights for the browser |
| `lm.js` | tokenizer, LSTM forward pass, temperature sampling, distributions |
| `test_infer.js` | Node parity check against the Python reference |
| `index.html` | stepwise browser demo |
| `README.md` | fuller run notes and historical results |

The committed corpora are `examples/happy_prince.txt`, `examples/dorian_gray.txt` and
`examples/tiny_stories.txt`; their sources and SHA-256 hashes are in
`examples/CREDITS.md`.
